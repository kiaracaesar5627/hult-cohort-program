# Novaris — Canva Brand Kit setup

Use this after signing in at [canva.com/brand](https://www.canva.com/brand). Values match the Google Form responses and `src/lib/brand.ts`.

## 1. Create brand

- **Brand name:** Novaris
- **Description:** Practice before the moment. Tools for high-stakes professional transitions.

## 2. Brand colors (add in this order)

| Swatch name   | Hex       | Use                          |
|---------------|-----------|------------------------------|
| Ink           | `#14181f` | Text, dark sections          |
| Paper         | `#f3f0ea` | Page background              |
| Panel         | `#fffdf8` | Cards / surfaces             |
| Band          | `#e8e3da` | Section dividers             |
| Muted         | `#5c6570` | Secondary text               |
| Teal          | `#0f766e` | **Primary accent**           |
| Burnt Orange  | `#c2410c` | **Secondary accent / CTAs**  |

**Harmony type (for your form):** Analogous neutrals with complementary accent.

## 3. Brand fonts

| Role        | Font      | Weight   |
|-------------|-----------|----------|
| Headings    | Fraunces  | Bold / Semi Bold |
| Subheadings | Fraunces  | Semi Bold |
| Body        | Figtree   | Regular / Medium |

If Fraunces is missing in Canva, search **Google Fonts** in the text picker or use **Libre Baskerville** as fallback.

## 4. Logo / mark (simple DIY in Canva)

1. New design → **Logo** (500×500 px).
2. Background: **Paper** `#f3f0ea`.
3. Add a small **diamond** (square rotated 45°) in **Teal** `#0f766e` — matches the site brand mark.
4. Text: **Novaris** in Fraunces Bold, **Ink** `#14181f`.
5. Optional subline: *Practice before the moment.* in Figtree, **Muted** `#5c6570`.
6. Save to Brand Kit → Logos.
