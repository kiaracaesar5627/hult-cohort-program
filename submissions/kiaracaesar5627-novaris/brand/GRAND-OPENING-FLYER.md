## Canva build (8.5" × 11")

### Setup
1. **Create design** → **Flyer (US Letter)** or custom **8.5 × 11 in**.
2. Background: **Paper** `#f3f0ea`.

### Layout (top → bottom)

| Zone | What to add |
|------|-------------|
| **Header band** | Full-width rectangle **Ink** `#14181f`. Place your **logo** (white/cream version) left. |
| **Hero** | Eyebrow: `YOU'RE INVITED` — Figtree, teal, small caps. Headline: **Grand Opening** — Fraunces 72–96pt, ink. Subtext: studio description — Figtree 18pt, muted. |
| **Accent line** | Thin bar: teal → burnt orange gradient (or solid teal). |
| **Details grid** | Two columns: **Date** \| **Time**, then full-width **Location**. Section labels in teal Fraunces caps. |
| **Highlights box** | Panel `#fffdf8`, left border teal 4px. Bullet list of opening-day offers. |
| **CTA** | Burnt orange rectangle, white text: **Join Us — Practice Before the Moment!** |
| **Footer** | Ink band with contact + website in cream text. |

### Imagery (appropriate, not cluttered)
- Subtle **teal diamond** shapes in background (low opacity) — matches logo  
- Optional: one professional photo (diverse job seekers / interview prep) from Canva — **don't** overcrowd  
- Optional: **QR code** linking to Interview Room: `https://kiaracaesar5627-project-4.vercel.app`

### Visual hierarchy
1. GRAND OPENING (largest)  
2. Novaris logo + name  
3. Date / time / location  
4. CTA  
5. Contact (footer)
