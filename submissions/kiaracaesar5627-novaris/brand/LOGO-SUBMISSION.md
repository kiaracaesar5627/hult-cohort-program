# Novaris logo — class submission guide

**Student file name:** `KiaraCaesar_BrandLogo.png` (or `.jpg` / `.pdf`)

## Logo design rationale

| Requirement | How Novaris meets it |
|-------------|----------------------|
| Business name | **Novaris** in large Fraunces wordmark |
| Typography | **Fraunces** (headline) + **Figtree** (tagline) |
| Symbol | **Threshold mark** — teal diamond (aris = raised ground) + ink baseline (threshold before the moment) |
| Colors (4) | Paper `#f3f0ea`, Ink `#14181f`, Teal `#0f766e`, Muted `#5c6570` |
| Composition | Horizontal lockup: mark left, name + tagline right |
| Original | Custom symbol + layout; not copied from existing brands |

**Tagline on logo:** *Practice before the moment.*

## Option B — Recreate in Canva (for Canva link requirement)

1. **Create design** → **Logo** → 500 × 500 px (or Custom 1280 × 400 for horizontal).
2. **Background:** `#f3f0ea` (Paper).
3. **Symbol** (your creative build — do not use a stock logo):
   - Add a **square**, size ~44×44, color `#0f766e`, **rotate 45°** (diamond).
   - Add a **rectangle** under it (~56×4), color `#14181f`, rounded corners (threshold line).
4. **Text:** **Novaris** — font **Fraunces Bold**, color `#14181f`, size ~64–72.
5. **Tagline:** *Practice before the moment.* — **Figtree Medium**, `#5c6570`, ~15px.
6. Align mark and text horizontally; leave generous whitespace.
7. **Share** → **Copy link** (Anyone with link can view) → paste in Google Classroom.
8. **Download** → PNG → rename to `KiaraCaesar_BrandLogo.png`.
